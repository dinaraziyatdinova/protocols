# Как передать файл

SMB удобен для сетевых папок, FTP разделяет управляющий и data-канал, а SSH позволяет защищённо работать с удалённым сервером и передавать файлы через SFTP.

## Цепочка протоколов

1. **[Ethernet](../01-core/ethernet.md)** — Описывает кадры локальной сети с MAC-адресами; коммутатор обучается адресам и пересылает кадры на нужный порт.
2. **[IP](../01-core/ip.md)** — Адресует пакеты и обеспечивает их пересылку между сетями по маршрутам. Доставка осуществляется по принципу best effort.
3. **[TCP](../01-core/tcp.md)** — Создаёт упорядоченный надёжный поток байтов. Использует номера последовательности, подтверждения и повторную передачу потерянных данных.
4. **[SMB](../02-application/smb.md)** — Обеспечивает общий доступ к файлам, каталогам и принтерам в сети; современные версии поддерживают шифрование и подписи.

## Альтернативы и дополнения

- [FTP](../02-application/ftp.md)
- [SSH](../03-security/ssh.md)

> Схемы иллюстрируют распространённый сценарий; реальная сеть может пропускать этапы из-за кеша, переиспользования соединений и особенностей конфигурации.
