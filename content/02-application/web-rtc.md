# WebRTC — Browser video calls

> Категория: **Прикладные протоколы** · Уровень: 7 · Прикладной · Транспорт: UDP / TCP

## Что это и для чего нужно

Набор технологий браузерной связи в реальном времени. Использует сигнализацию для согласования сессии и старается доставлять медиа напрямую между участниками.

**Пример применения:** Видеозвонки и совместная работа в браузере.

## Как это работает

1. **Сигнализация**
2. **Узнать внешний адрес (STUN)**
3. **Предложение SDP**
4. **Ответ SDP**
5. **Проверка соединения**
6. **DTLS для ключей**
7. **Передача аудио и видео**
8. **Резервный путь через relay**

## На что обратить внимание

Прямой P2P путь возможен не всегда: иногда требуется relay-сервер TURN.
