# HTTP — Hypertext Transfer Protocol

> Категория: **Прикладные протоколы** · Уровень: 7 · Прикладной · Транспорт: TCP

## Что это и для чего нужно

Протокол запросов и ответов между клиентом и веб-сервером. Метод указывает действие, статус сообщает результат, заголовки описывают сообщение, а тело переносит данные.

**Пример применения:** Загрузка HTML-страницы и работа веб-API.

## Как это работает

1. **Запрос клиента**
2. **Разрешение DNS**
3. **Соединение TCP**
4. **Обмен HTTP**
5. **Отображение страницы**

## На что обратить внимание

Обычный HTTP не шифрует содержимое соединения.
