# HTTP vs HTTPS

**Вопрос:** Зачем вебу шифрование.

| Критерий | HTTP | HTTPS |
|---|---|---|
| Роль | Протокол запросов и ответов между клиентом и веб-сервером. Метод указывает действие, статус сообщает результат, заголовки описывают сообщение, а тело переносит данные. | HTTP, защищённый шифрованием и проверкой подлинности сервера. Для HTTP/1.1 или HTTP/2 обычно используется TLS поверх TCP; для HTTP/3 — QUIC. |
| Слой | 7 · Прикладной | 7 + TLS |
| Транспорт | TCP | TCP / QUIC |
| Порты | 80 | 443 |
| Пример | Загрузка HTML-страницы и работа веб-API. | Безопасный доступ к сайтам, личным кабинетам и API. |
| На что смотреть | Обычный HTTP не шифрует содержимое соединения. | Значок замка не гарантирует честность самого сайта. DNS-запросы и адрес сервера могут быть видны отдельно. |

**Вывод:** сравнивайте протоколы по задаче, которую они решают. Иногда они дополняют друг друга, а не заменяют.
