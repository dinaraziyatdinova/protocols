# DNS vs DNS over HTTPS

**Вопрос:** Обычный DNS и DNS поверх HTTPS.

| Критерий | DNS | DNS over HTTPS |
|---|---|---|
| Роль | Преобразует доменные имена в записи разных типов: A, AAAA, MX и другие. Рекурсивный резолвер получает и кеширует ответы от DNS-серверов. | Переносит DNS-запросы через защищённое HTTPS-соединение. Скрывает DNS-содержимое от наблюдателя на участке клиент—DoH-резолвер. |
| Слой | 7 · Прикладной | 7 · Прикладной |
| Транспорт | UDP / TCP | HTTPS |
| Порты | 53 | 443 |
| Пример | Поиск IP-адреса сайта и почтового сервера. | Приватные DNS-запросы из браузера. |
| На что смотреть | DNS не всегда означает один запрос: результат может быть в кеше; обычный DNS не шифрует вопросы. | DoH не скрывает DNS-вопросы от самого резолвера и не заменяет DNSSEC. |

**Вывод:** сравнивайте протоколы по задаче, которую они решают. Иногда они дополняют друг друга, а не заменяют.
