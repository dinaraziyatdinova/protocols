# IMAP vs POP3

**Вопрос:** Синхронизация и загрузка почты.

| Критерий | IMAP | POP3 |
|---|---|---|
| Роль | Работает с папками и флагами писем на сервере. Позволяет синхронизировать состояние почты на разных устройствах. | Загружает письма с сервера по простой модели mailbox retrieval. Может помечать сообщения на удаление до завершения сессии. |
| Слой | 7 · Прикладной | 7 · Прикладной |
| Транспорт | TCP + TLS (при защите) | TCP + TLS (при защите) |
| Порты | 143 / 993 | 110 / 995 |
| Пример | Почтовый ящик на ноутбуке и телефоне одновременно. | Получение писем на один почтовый клиент. |
| На что смотреть | IMAP — не протокол отправки писем; он управляет доступом к хранящимся сообщениям. | Удаление обычно применяется при QUIT; POP3 хуже подходит для синхронизации множества устройств. |

**Вывод:** сравнивайте протоколы по задаче, которую они решают. Иногда они дополняют друг друга, а не заменяют.
