# Глоссарий

- **OSI** — Условная семиуровневая модель, помогающая классифицировать функции сетевых технологий.
- **TCP/IP** — Практический набор протоколов интернета: связь приложений, транспорта, сетевой и канальной передачи.
- **Пакет** — Единица передачи данных на сетевом уровне, например IP-пакет.
- **Кадр** — Единица передачи канального уровня, содержащая MAC-адреса и полезную нагрузку.
- **Датаграмма** — Самостоятельное сообщение, например UDP-датаграмма.
- **Порт** — Числовой идентификатор конечной точки протокола TCP или UDP.
- **IP-адрес** — Логический адрес интерфейса или узла в сети IP.
- **MAC-адрес** — Адрес интерфейса на канальном уровне, используемый в локальном сегменте.
- **DNS-резолвер** — Узел, который принимает запросы имён и находит или кеширует DNS-ответы.
- **TTL** — В IP — лимит переходов между маршрутизаторами; в DNS — срок действия кешированной записи.
- **Маршрутизатор** — Устройство, выбирающее следующий сетевой переход для IP-пакета.
- **Шлюз по умолчанию** — Маршрутизатор, которому хост передаёт трафик за пределы локальной подсети.
- **NAT** — Преобразование сетевых адресов и иногда портов на границе сети.
- **DHCP-аренда** — Временное назначение IP-адреса и сетевых параметров.
- **ACK** — Подтверждение получения или отдельный тип управляющего сообщения в ряде протоколов.
- **SYN** — Флаг TCP, применяемый при начале установки соединения.
- **Handshake** — Рукопожатие — последовательность сообщений для установления параметров соединения.
- **MTU** — Максимальный размер передаваемого блока на участке сети без фрагментации.
- **AS** — Автономная система — сеть или группа сетей с единой политикой маршрутизации.
- **BGP route** — Объявленный маршрут к сетевому префиксу между автономными системами.
- **TLS-сертификат** — Подписанный документ, связывающий публичный ключ с именем сервера или другой сущностью.
- **Шифрование** — Преобразование информации, делающее содержание недоступным без ключа.
- **Аутентификация** — Проверка подлинности участника или системы.
- **Целостность** — Свойство данных, позволяющее обнаружить их несанкционированное изменение.
- **HTTPS CONNECT** — Метод создания TCP-туннеля через HTTP-прокси к указанному узлу.
- **VPN** — Виртуальная частная сеть — защищённый логический канал для выбранного сетевого трафика.
- **SDP** — Формат описания медиасессии для согласования параметров связи.
- **STUN** — Помогает определить наблюдаемый снаружи адрес и свойства NAT.
- **TURN** — Сервер-посредник для передачи медиатрафика, если прямой путь недоступен.
- **RTP** — Протокол доставки аудио и видео в реальном времени.
- **MX** — DNS-запись, указывающая почтовые серверы домена.
- **SMTP-конверт** — Отдельные от заголовков письма адреса отправителя и получателя в SMTP-сессии.
- **RRSIG** — DNSSEC-запись с цифровой подписью набора DNS-данных.
- **SAE** — Механизм обмена при подключении WPA3-Personal.
- **PLC** — Программируемый логический контроллер для промышленной автоматизации.
- **RPKI** — Инфраструктура цифровых свидетельств, помогающая проверять авторизацию BGP-префиксов.
