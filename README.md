# PROTOCOL ATLAS

**Интерактивная база знаний по 39 сетевым протоколам.** Итоговый проект по материалам [Protocol Explorer](https://protocol-explorer-alpha.vercel.app/).

## О проекте

Цель — **не пересказать протоколы по алфавиту**, а выстроить логическую модель интернета и показать, как разные технологии работают вместе. В интерактивном интерфейсе доступны каталог, карта связей, сравнения, жизненные сценарии и словарь.

### Структура знаний

| Раздел | Что содержит | Количество |
|---|---|---:|
| **Core** | Канальная сеть, маршрутизация, транспорт и диагностика | 11 |
| **Application** | Веб, почта, звонки, файлы, настройка сети, прокси и OT | 19 |
| **Security** | TLS, защищённый DNS, Wi-Fi, SSH и VPN | 9 |
| **Сценарии** | Реальные цепочки взаимодействия протоколов | 5 |
| **Сравнения** | Пары технологий и их различия | 9 |
| **Глоссарий** | Важные термины | 36 |

### Рекомендуемый маршрут изучения

`Ethernet / Wi-Fi → IP → TCP / UDP → DNS → HTTP → TLS / HTTPS`

Потом можно переходить к почте (SMTP, IMAP, POP3), видеосвязи (WebRTC, SIP), прокси, VPN и промышленным протоколам.

## Запуск

**Вариант 1.** Просто открыть `index.html` в браузере. Никакие пакеты устанавливать не нужно.

**Вариант 2.** GitHub Pages: **Settings → Pages → Deploy from a branch → main → / (root) → Save**. После публикации сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

## Что демонстрирует проект

1. **Систематизация:** выделены роли, уровни, транспорт, типичные порты и ограничения каждого протокола.
2. **Взаимосвязи:** каждую карточку можно открыть из связанных карточек и изучить на визуальной карте; заметки содержат гиперссылки.
3. **Практический контекст:** вместо разрозненных определений показаны цепочки «от Wi-Fi до HTTPS» и другие сценарии.
4. **Анализ:** для похожих протоколов сделаны сравнительные таблицы.
5. **Навигация:** поиск по именам/терминам, фильтры категорий и тематические маршруты.

## Источники и ограничения

Материалы систематизированы на основе [Protocol Explorer](https://protocol-explorer-alpha.vercel.app/); собственные объяснения написаны на русском языке. Указанные порты — распространённые, а не единственно возможные. Схемы являются учебными упрощениями. Подробнее: [Источники и метод](content/08-sources.md).

**Автор проекта:** учебная систематизация материалов Protocol Explorer.
